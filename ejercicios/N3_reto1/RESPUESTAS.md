# N03 · S06 · Postre

- espacio 1 → `Postre`: el constructor se llama igual que la clase y no lleva tipo de retorno.
- espacio 2 → `this`: distingue el atributo del parámetro que tiene el mismo nombre.
- espacio 3 → `this`: el constructor corto llama al completo de la misma clase.
- espacio 4 → `false`: la salida del Brownie no dice «sin azúcar».
- espacio 5 → `boolean`: el parámetro se usa como condición y Main envía `true`.
- espacio 6 → `etiqueta`: reutiliza la sobrecarga sin parámetros.
- espacio 7 → `new`: crea el objeto llamando al constructor.

**Sobran:** `Brownie`, `int`, `true`, `super`, `void`.
