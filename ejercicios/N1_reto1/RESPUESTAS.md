# N01 · S06 · Mesa

- espacio 1 → `class`: se está declarando el molde `Mesa`.
- espacio 2 → `boolean`: `ocupada` recibe `true` y `false`.
- espacio 3 → `void`: `liberar` cambia atributos pero no devuelve nada.
- espacio 4 → `return`: `estado()` promete un `String` y debe entregarlo.
- espacio 5 → `new`: sin `new` no existe el objeto, solo la variable.
- espacio 6 → `ocupar`: es el método que recibe un `int` (cuántas personas).
- espacio 7 → `estado`: devuelve el texto que se imprime; `liberar` es `void`.

**Sobran:** `int`, `Mesa()`, `liberar`, `String`, `static`.
