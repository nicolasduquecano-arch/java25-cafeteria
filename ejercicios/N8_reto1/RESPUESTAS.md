# N08 · S06 · Bandeja

- espacio 1 → `<T>`: declara el parámetro de tipo de toda la clase.
- espacio 2 → `T`: la lista guarda el mismo tipo que la bandeja.
- espacio 3 → `<>`: diamante, el compilador deduce el tipo.
- espacio 4 → `T`: solo se puede poner el tipo con que se creó la bandeja.
- espacio 5 → `T`: devuelve ese mismo tipo, sin cast.
- espacio 6 → `String`: Main pone textos.
- espacio 7 → `cantidad`: es el método público que dice cuántas cosas hay; `size` es de la lista privada.

**Sobran:** `Integer`, `E`, `size`, `?`, `Object`.
