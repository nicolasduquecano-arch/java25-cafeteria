# N05 · S06 · Snack, Descontable y Galleta

- espacio 1 → `interface`: es un contrato; tiene un método sin cuerpo y no guarda estado.
- espacio 2 → `default`: en una interfaz, un método de instancia con cuerpo y heredable lleva `default`.
- espacio 3 → `abstract`: la clase tiene un método abstracto, así que no se puede instanciar.
- espacio 4 → `implements`: Snack firma la interfaz `Descontable`.
- espacio 5 → `abstract`: el método termina en `;`, no tiene cuerpo.
- espacio 6 → `extends`: Galleta hereda de una clase, no de una interfaz.
- espacio 7 → `Descontable`: `d` se usa por el contrato, con `conDescuento`.

**Sobran:** `super`, `Galleta`, `final`, `static`, `class`.
