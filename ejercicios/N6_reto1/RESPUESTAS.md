# N06 · S06 · Leche

- espacio 1 → `enum`: es una lista cerrada de constantes.
- espacio 2 → `final`: el recargo de cada leche se asigna una vez y no cambia.
- espacio 3 → `Leche`: el constructor se llama igual que el enum.
- espacio 4 → `switch`: elige el resultado según la constante (`this`).
- espacio 5 → `default`: un switch que devuelve valor debe cubrir todos los casos.
- espacio 6 → `values`: da el arreglo con todas las constantes para recorrerlas.
- espacio 7 → `recargo`: es el método que devuelve el recargo que se imprime.

**Sobran:** `class`, `ordinal`, `case`, `static`, `valueOf`.
